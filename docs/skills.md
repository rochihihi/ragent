# RAgent 项目技能

点击会话标题旁的“技能”，管理当前项目的完整技能包。技能提供业务流程指导，不增加执行权限；导入、预览和加载不会执行脚本或安装依赖。

## 导入与管理

支持四种来源：完整文件夹、ZIP、单个 `SKILL.md`、粘贴说明文本。一个技能包的根目录必须包含 `SKILL.md`；ZIP 也可以只包一层外部目录。一次导入一个技能包，可以多次导入不同技能。

先点击“检查并预览”，查看名称、描述、环境要求和文件列表，确认来源可信后导入。`scripts/`、`references/`、`assets/` 等配套文件原样保存，不会自动执行。

保存位置：项目 `.agents/skills/<name>/`。导入的新技能默认允许在当前会话自动选择；手动放入项目的技能默认禁用，须在管理界面确认使用方式。旧会话中原先勾选的技能兼容为固定启用。

管理界面提供搜索、刷新、说明编辑、资源预览、模式保存、同名更新及删除。文本资源预览最多显示 32000 字符，不截断原文件；二进制资源显示类型和体积。无效技能的错误会展示，不再静默消失。

Windows 导入目录继承项目权限，不使用会生成私有受保护 ACL 的临时目录。旧版导入的包如果在沙箱内报 `Permission denied`，选择该技能，点击“修复执行权限”并确认：原包先备份，再原样重新保存以继承项目权限。此操作不新增账户授权、不关闭沙箱、不执行脚本，也不改变会话使用方式；修复后仍需在当前会话启用技能。项目本身没有沙箱访问权限时，修复技能目录不能替代项目授权。

同名技能不能静默覆盖。更新须预览并明确确认；预览后的原包发生变化会拒绝更新。说明编辑保留配套资源，不允许顺便改名。更新和删除会把原目录移入项目 `.agents/skill-backups/<name>-<随机标识>/`。可在“历史版本”中确认恢复完整技能包，包括已删除的技能；当前文件先备份，预览后的版本发生变化则拒绝恢复。备份和历史版本不自动清理。

技能文件属于项目，使用方式按会话保存。当前会话运行中或等待审批时禁止管理修改，结束后刷新再操作。其他会话更新或删除技能，不会改变已有任务绑定的完整版本；新任务按最新发布状态加载。

## 三种使用方式

| 模式 | 行为 |
| --- | --- |
| 自动选择 | 向模型提供名称、描述和位置。模型判断适用后，通过 `read` 加载完整说明。 |
| 固定启用 | 当前会话每次请求直接加载完整说明，最多 10 项。 |
| 禁用 | 不进入技能目录，也不允许作为技能激活。不是禁止把文件作为普通项目数据搜索的安全隔离。 |

选择模式后点击“保存使用方式”。自动模式下可以发送 `$sales-analysis 分析这份报表` 显式加载已允许的技能，不必等模型选择。行内代码、三反引号代码块及转义的美元符号不作为显式激活标记。

使用方式按会话保存：在一个会话导入技能，不会自动替另一个会话启用。显式指定已禁用技能时会直接暂停并提示先保存使用方式，不继续调用模型改读脚本。

## 加载与执行

1. 第一级：可用技能的名称、描述、位置和环境要求进入模型上下文，不发送全部正文。
2. 第二级：模型读取目录中的 `SKILL.md` 时，运行时返回完整说明（不受普通文件读取 240 行限制），保存为本次任务的活动技能。
3. 第三级：模型根据说明按需读取参考资料，或经已有命令执行工具运行脚本。相对资源路径以技能目录为基准，不以项目工作目录为基准。

固定启用和 `$name` 会直接完成第二级。任务中已加载的技能复用快照，暂停/审批恢复时保留；新的请求重新建立活动集合。正常裁剪、超时重试和压缩异常恢复均保留活动技能，不静默截断说明。必要上下文超出模型预算时暂停并说明原因。

技能脚本仍走现有权限审批和沙箱。脚本使用 Python、Node 等解释器及第三方依赖时，需要环境实际提供它们；EXE 不是通用 Python 解释器，导入技能不保证其依赖已可用。`compatibility` 提供环境说明，不会自动安装。其他客户端专有的授权字段不授予 RAgent 权限。

## 热更新与版本一致性

- 应用启动时监视最近会话的项目，打开技能管理或执行任务时也会加入监视。每 0.5 秒检查文件元数据，变更静默 1 秒后才捕获、校验并发布；未变化时不重复读取整包资源。界面每 3 秒刷新版本信息，不覆盖未保存的编辑内容。
- 发布前检查包格式、路径、大小、Python 语法和可选冒烟清单；两次内容捕获一致后，将完整包按 SHA-256 保存到 `.agents/skill-runtime/versions/<name>/<hash>/`，最后通过临时文件、fsync 和原子替换提交注册表。失败保留上次发布版本，并展示错误。
- 每个新任务绑定所有可用技能的完整版本，不只是 `SKILL.md`。暂停、审批和重启恢复继续使用同一版本；脚本、参考资料和模板均来自该快照。读取/直接命令参数中的原安装路径会在审批前映射为绑定路径；不能安全改写的 shell 字符串会拒绝并要求使用版本绝对路径。
- 原生文件修改工具禁止写版本目录，默认沙箱也拒绝写入。使用前校验内容哈希，篡改时拒绝使用。进程内引用计数在任务结束、取消或异常时释放；为了支持暂停任务与历史恢复，磁盘版本不因计数归零而删除。技能版本不持有连接等资源。

防抖不能证明外部程序已写完：外部更新请先写临时文件，再原子替换，整包更新应采用暂存目录后切换；一个静态合法但业务不完整的半成品仍可能通过静态校验。应用内管理更新采用暂存/备份流程。注册表锁和引用计数适用于单个应用进程，不是多进程/分布式发布服务。宿主机外部编辑器或明确批准的沙箱外命令不受快照写保护保证。

## 冒烟测试、灰度与回退

在技能详情展开“发布、灰度与冒烟测试”。默认只做静态检查，不会把它描述成实际功能测试通过。可在包中增加 `tests/smoke.json`：

```json
[
  {"script": "scripts/analyze.py", "args": ["--help"], "contains": "--input"},
  {"script": "scripts/analyze.py", "args": [], "contains": "269.80"}
]
```

目前支持 1–10 个包内 Python 脚本样例。包含该清单的新版先保持待发布；明确勾选确认后，使用外部 Python 在默认沙箱内执行，每例最多 30 秒。检查实际沙箱标记、退出码及输出片段；缺解释器、依赖、沙箱或测试失败均不能标记通过，不会自动安装或退到宿主执行。通过后点击“保存发布策略”。测试仍可能产生沙箱允许的副作用，输出只返回当前界面，不写入持久注册表。

首次发布必须为 100%，因为还没有旧稳定版。已有稳定版时，可将新版流量设为 0–99%；按任务 ID 哈希稳定分流，任务中途不切版本。保存的比例也用于后续导入和监听更新；100% 表示全量发布。

历史页展示最近 100 次脚本执行的次数、失败数、平均耗时及正在使用的引用数；注册表另记录最近 100 次任务完成情况。可选择按最少执行样本（至少 3）、失败比例和平均耗时阈值自动回退：灰度版停止分流，全量新版回到未被隔离的前一版；没有可信旧版时停止新任务加载。异常版本被隔离，监听不会自动把相同内容发布回来；手动确认重新发布/恢复可解除隔离。重新发布重新计算监控窗口，历史指标保留。

执行指标来自实际调用结果，不是模型对业务正确性的评分；任务完成率也不等于答案准确率。未结束的后台进程不计成功样本。依赖/权限故障同样可能影响指标，因此自动回退默认关闭。回退只改变后续任务的版本，既有任务保持快照；文件修改、网络请求等已发生的副作用不会自动撤销。

## 格式与限制

```markdown
---
name: sales-analysis
description: >-
  分析销售 CSV，按日期统计销售额、销量和商品排名。
compatibility: Python 3.11+，只使用标准库
metadata:
  version: "1.0"
---
使用 scripts/analyze.py 统计实际数据；不确定参数时先运行 --help。
金额口径不清楚时向用户确认；按需读取 references/data-rules.md。
```

- 使用 PyYAML 安全解析，支持多行描述、`compatibility`、字符串 `metadata`。拒绝重复字段、对象构造标签、YAML 别名及过深结构。
- 名称最长 64 字符，小写字母、数字、短横线；兼容已有下划线名称。必须与安装目录名一致。
- 单个说明最多 12000 字符；活动指导合计最多 60000 字符，仍须符合模型上下文预算。
- 包最多 200 个文件、合计 8 MiB，单文件最多 2 MiB；ZIP 本身也最多 8 MiB。上传 JSON 请求上限 16 MiB。
- 拒绝路径越界、绝对路径、Windows 特殊路径/设备名、链接/目录联接和大小写冲突。导入先写暂存目录，校验成功后提交；替换失败会恢复旧目录。
- 尚不支持 GitHub 在线安装、全局技能目录、技能商店或自动安装依赖。

## 验证

```powershell
python -m pytest tests/test_skill_runtime.py tests/test_skill_packages.py tests/test_studio_skills.py tests/test_runtime_simplification.py -q
```

测试覆盖包导入与路径安全、更新冲突/备份/回滚、监听防抖与旧版本保护、并发完整快照、灰度分流/自动回退/历史恢复、API 管理、目录和正文分离、完整指导加载、显式激活及压缩保护。模型选择行为的自动化测试使用本地假模型，不代表对真实供应商效果的评估。

安装好 Windows 沙箱并提供外部 Python 后，可做明确启用的真实端到端自检：

```powershell
.\dist\RAgent.exe --self-check-sandbox "C:\临时目录\skill-sandbox-check.json"
```

该自检不安装账户或修改沙箱设置，使用隔离项目验证新导入脚本的帮助与计算、旧版私有目录修复、备份和内容不变；正常释放沙箱 ACL 租约。测试技能包位于 `examples/skills/sales-report-demo/`。
