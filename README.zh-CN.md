# RAgent

**一个本地优先、由模型决策、工具执行受控且过程可审计的桌面编程 Agent。**

[English README](README.md)

![RAgent 桌面工作区](assets/ragent-studio-20260930.png)

RAgent 将 DeepSeek 或 OpenAI 模型接入受控的本地项目工作区。执行模型理解用户原始请求、选择结构化动作，并决定何时回复。本地运行时负责路径边界、权限检查、安全文件操作和状态持久化，同时记录工具结果与验证证据。

桌面 Studio 默认 Auto/Quick 模式将证据交回模型，不强制固定的“测试后重新打开”流程。Strict 严格验证模式可选，会增加本地完成门禁。一轮对话已完成不等于测试已通过，验证状态会单独显示。

## 核心能力

- **结构化 Agent 循环**：规划、项目检索、代码修改、命令执行、结果观察、失败恢复和完成响应均使用明确的动作协议。
- **验证证据管理**：文件变化后废弃旧验证证据；默认模式由模型选择相关检查，Strict 模式额外启用本地验证门禁。
- **分层长上下文管理**：分别管理当前需求、任务状态、近期对话、文件证据和历史信息，在接近预算时压缩低优先级内容。
- **原始请求优先**：执行模型结合用户原始请求与对话理解意图，不再单独进行前置意图分类。计划和任务摘要只是辅助信息，不能替代用户指令。
- **暂停与继续**：桌面任务默认不设置固定决策步数上限。暂停会取消等待中的模型请求；同步工具执行完并保存结果后再暂停，之后可继续已保存的工作。
- **新建语义保护**：新建路径已存在时返回冲突，不再自动转成修改。模型可以选择新路径；这不妨碍用户明确要求的编辑操作。
- **回答审计**：默认模式单独记录证据审查，不把模型回答替换成固定的证据兜底文案；Strict 模式的审查仍可能要求模型纠正回答。
- **范围化权限系统**：根据操作类型、目标路径、影响和风险进行判断，支持单次允许与本会话同类操作授权。
- **持久化与恢复**：使用 SQLite 保存会话、计划、观察、文件变更和上下文摘要，中断后可以从现有证据继续。
- **本地项目工作台**：提供持久化对话、层级文件树、文件/文件夹创建、Diff 审查、Git 操作、执行轨迹与上下文占用展示。
- **本地凭据管理**：API 密钥通过操作系统 Keyring 保存，不写入项目仓库或会话数据库。

## 工作流程

```mermaid
flowchart LR
    U[用户原始请求] --> C[任务状态]
    C --> X[构建分层上下文]
    X --> M[DeepSeek / OpenAI]
    M --> D[结构化决策]
    D --> T[受控工具]
    T --> O[观察与证据]
    O --> X
    D --> A[最终回复]
    A --> V{按模式审查}
    V -->|默认审计 / 严格模式通过| R[结果与验证状态]
    V -->|严格模式需要纠正| X
    C <--> S[(SQLite 检查点)]
    O --> S
```

模型可以请求读取与搜索项目、精确编辑、文件操作、验证命令或最终回复。所有副作用操作都会先经过工作区边界和权限策略检查。

工具结果（包括测试成功或打开请求已执行）会交回模型，本地流程不要求验证后再次打开产物。意图理解与动作选择由模型决定；路径检查、权限执行、新建冲突和暂停处理属于本地控制。

## 桌面工作区

界面由三个协同区域组成：

1. **工作区**：会话列表、项目文件树、嵌套目录、变更标记，以及直接新建文件和文件夹。
2. **对话区**：自然语言任务、Markdown 与代码显示、完成证据、运行诊断和任务纠正。
3. **执行记录**：模型决策、工具结果、权限事件、验证记录、上下文占用和压缩历史。详细/全部记录视图读取完整的已保存事件历史，可查看长消息与工具载荷。

Git、升级验收、技能、模型配置、验证模式、回答风格和推理强度均可在工作台内完成配置。

## 安全边界

- 文件访问前会解析并校验真实路径，防止越出当前工作区。
- `.git`、`.github`、`.codex` 等项目元数据不能通过文件工具修改。
- 命令执行前必须通过能力分析和权限判断。
- 删除等高风险操作必须明确授权，并显示实际影响范围。
- 默认由模型决定完成并记录证据审计，Strict 模式增加本地门禁。“已完成”或“已请求打开”本身不代表测试通过，也不代表已经目视验证界面。
- 凭据不会进入提示词、SQLite 事件、日志或 Git。

| 模块 | 技术 |

## 快速开始

### 从源码运行

```powershell
git clone https://github.com/rochihihi/ragent.git
cd ragent
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,desktop]"
.\.venv\Scripts\ragent-desktop.exe
```

在应用设置中配置模型服务，选择本地项目文件夹，然后创建对话即可。

### 构建 Windows 程序

安装 Node.js 和 Python 依赖后运行：

```powershell
.\.venv\Scripts\python.exe scripts\build_desktop.py
```

打包结果位于 `dist/RAgent.exe`。

### 启动本地 Web 工作台

```powershell
.\.venv\Scripts\ragent.exe serve --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。RAgent 默认面向本地使用，不应直接作为公网执行服务暴露。

## 验证项目

```powershell
.\.venv\Scripts\python.exe -m pytest -q
cd frontend
npm install
npm run check
npm run test:trace
npm run build
```

测试覆盖原始请求优先、新建冲突、模型回答保留、暂停/继续、权限边界、上下文压缩、验证模式、完整执行历史、状态持久化和失败恢复等核心行为。
